# Internship Hub – Learning Management and Internship Tracking Platform

- Internship Hub is a full-stack web application that helps Students, Mentors, and Admins manage internship learning and track progress. It includes features such as authentication, assignments, resources, internship diary, project tracking, leave requests, and feedback.

## Tech Stack
- Frontend: React.js, Vite, Tailwind CSS
- Backend: Spring Boot, Spring Security, JWT
- Database: PostgreSQL (Supabase)

## Features
- User Registration and Login
- Role-Based Access (Student, Mentor, Admin)
- Learning Resources and Recordings
- Assignments and Submissions
- Internship Diary
- Project Tracking
- Leave Requests
- Feedback and Messaging

## Run the Project
### Backend
- cd backend
- mvn spring-boot:run

### Frontend
- cd frontend
- npm install
- npm run dev
